Prijzen beheren

Pas hier je prijzen aan en tik op Opslaan. Na 1 tot 2 minuten staan de nieuwe prijzen overal op je website: in de calculator, de tabellen en de teksten.

1. Koppeling met GitHub

Eenmalig instellen op dit toestel. Zonder koppeling kun je de prijzen wel bekijken, maar niet opslaan.

Hoe maak ik een toegangscode?
  1. Open github.com/settings/personal-access-tokens/new en log in.
  2. Naam: bijvoorbeeld Prijzen website. Bij Expiration kies je bijvoorbeeld 1 jaar.
  3. Bij Repository access: kies Only select repositories en selecteer de-composiet-specialist.
  4. Bij Permissions → Repository permissions: zet Contents op Read and write.
  5. Tik onderaan op Generate token, kopieer de code en plak hem hierboven.

De code werkt alleen voor deze ene website. Deel hem met niemand. Kwijt of uitgelekt? Verwijder hem op GitHub en maak een nieuwe.
